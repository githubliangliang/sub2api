| #6188 中的行为 | 本地适配 | 规格 |
|---|---|---|
| 改写前从显式请求字段或模型后缀读取强度 | 区分客户端提供的值与桥接默认值；保留本地已支持的 `none`、`max` 及各模型校验 | E1 |
| 处理器、共享转发结果和 WS 结果携带两份值 | 在 HTTP 重试和延迟写入中保留初始请求值，WS 按每个 `response.create` 单独取值 | E2 |
| usage 新列、多个 insert 与 scan 路径 | 使用本地 SQLite 可空列；沿用既有结算与去重身份；缺请求值时将展示回退留在读取层 | E3 |
| 用户字段、管理员差异字段、表格与导出 | 用户保持 `reasoning_effort` 字段，管理员专有 `upstream_reasoning_effort`；两个角色的导出跟随各自权限 | E4 |
