# Why

现有网关与管理界面仍有协议、结算和输入边界缺口，小范围补丁可改善单节点可靠性。

- F02 Chat 请求角色与具名工具选择。
- F03 Anthropic 缓冲索引与 thinking 输出。
- F04 Claude 拟态缓存 TTL 与 Sonnet 采样参数。
- F05 Grok 空完成事件与 SSO consent。

- F07 Gemini 工具图片与 Antigravity 图片冷却隔离。

- F09 共享弹窗和选择器输入边界。
- F10 管理端错误文本与开关响应。
- F11 计时器、访问重试与备份卸载。

## Impact

只采用选定行为及必要基座，不新增支付、供应商平台、缓存管理、模型规则scope或新模型。保持当前schema与已完成固定quota窗口修复；第二档S16允许后续定向维护已有依赖，禁止整取上游lockfile。

## Non-goals

不实施第三/四档，不修改历史迁移，不改变VERSION，不发布部署，不把评估probe当新行为验收。
