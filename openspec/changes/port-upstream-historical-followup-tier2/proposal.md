# Why

真实Vue探针确认旧用户读取覆盖新用户、分组加载失败仍提交空授权列表、旧图片读取覆盖新选择或删除，以及旧模板关联列表覆盖当前列表。这些是现有管理页面/共享组件的合同缺口，明确从第三档调整为第二档。

# What Changes

按当前用户、对话框或文件选择划定异步读取、错误、loading、提交和完成回调所有权；未完成或失败加载不得当成显式清空。复用已有接口和公开/专属分组语义，不引入新权限策略。

# Impact

只维护现有消费者；保持VERSION1.1.28、Go1.27.4、SQLite230/auth21、依赖/生成代码及既有资源默认。

# Non-goals

新多人策略、公共分组限制、native用户监控页恢复、图片数量/尺寸/上传上限扩展、备份/支付、性能缓存/新平台、发布/归档/业务实例操作不在本批范围。
