# 设计与适配决策

采用v0.2.11终态，按行为手工适配本地消费者，不整文件覆盖或按微提交顺序机械套用。来源文件态与关键符号见[PORTING](../../../docs/upstream-sync/PORTING-0.2.11.md)。

| 簇 | 保留边界 |
|---|---|
| F01 | 只改选中的工具名；内置工具、参数、缓存断点和未映射名称保留。排除图片keepalive测试的无关sleep。 |
| F02 | 覆盖创建、编辑、批量编辑的现有账号表单；不引入分组model_allowlist schema。 |
| F03 | 无fallback仍拒绝；循环、缺失或不可用目标不得绕过现有检查。 |
| F04 | 前端不代替服务端授权；其它分组的现有客户端选项保持。 |

## 实施与数据边界

无迁移/依赖变动；不恢复裁剪菜单、支付功能或缺失平台。共享文件串行编辑，以目标场景失败/通过证明行为；旧消费者和正常反例一起回归。成功用量仍只落一次。
