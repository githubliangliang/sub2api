# Why

当前透传上下文错误只净化 query 参数，配置主机名和账号密钥仍会随可操作错误消息交给客户端。需要最小范围修复现有输出。

# What Changes

- F01 透传上下文错误的账号凭据与主机名脱敏：已有 OpenAI 透传错误向客户端保留上游消息时 SHALL 隐去配置的账号凭据与上游主机名，并保留有助于客户端恢复的非敏感错误语义。

# Impact

新增标准库级错误净化 helper，接入既有客户端错误写回。不需要迁移、生成代码、依赖或前端改动。 保持 SQLite230/auth21、VERSION1.1.27、Go1.27.4 和既有资源默认。

# Non-goals

身份变量、WS pool 身份分桶、上游名称备注同步、include=group、group i18n、新平台/模型、支付、发布/push/归档和业务实例操作均不在本批范围。
