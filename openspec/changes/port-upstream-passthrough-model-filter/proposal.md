# OpenAI 透传账号按模型筛选

## Why

同一分组可以同时有通用 OpenAI 账号和只提供少数模型的兼容上游。现有透传账号在候选判断中直接跳过模型映射，限定模型的上游仍可能收到自己不能处理的请求。普通模型列表又会收集其映射键，两处对同一账号的解释不同。

## What Changes

在已有 OpenAI 透传功能内增加默认关闭的账号开关。管理员启用后，调度和模型目录使用同一组来源模型规则。请求匹配现有精确或通配映射键即可选择该账号，转发仍沿用透传的模型名和正文。创建、编辑、批量编辑均可配置。

## Capabilities

- 新增 `openai-passthrough-model-filter`。

## Impact

涉及账号编辑、调度候选与快照、普通模型列表及 Codex 目录。复用账号 `extra` 和 `credentials.model_mapping`，不需要 SQLite 迁移。旧账号即使留有映射也须先显式开启筛选。本提案可独立于用量日志提案实施。
