# Why

既有安装、网关跨路径状态和异步页面仍存在缺口，需要在SQLite和现有目录架构下适配。当前依赖audit也要求重新处理旧维护待办。

## What Changes

- S01 首次安装管理员校验统一。
- S02 旧版函数调用与拒答转换完整性。
- S03 显式工具变更 beta 保留及旧前置。
- S04 WebSocket 逐轮分组价格与图片用量。
- S05 受约束的上游兼容重试。
- S06 OAuth 搜索历史回放声明。
- S07 组合路由公开模型目录。
- S08 删除分组同步清理风控范围。
- S09 分组倍率/RPM 编辑异步隔离。
- S10 异步页面、草稿、确认与弹窗隔离。
- S11 GPT-6.1 Sol 上游订阅长上下文统计。
- S12 Gemini 既有路径的错误、额度和脱敏修复。
- S13 监控配置补充已有平台入口。
- S14 Responses 无 namespace 时避免重建。
- S15 Chat 流心跳保活。
- S16 前端依赖安全维护与旧待办归并。

## Impact

只采用选定行为及必要基座，不新增支付、供应商平台、缓存管理、模型规则scope或新模型。保持当前schema与已完成固定quota窗口修复；第二档S16允许后续定向维护已有依赖，禁止整取上游lockfile。

## Non-goals

不实施第三/四档，不修改历史迁移，不改变VERSION，不发布部署，不把评估probe当新行为验收。
