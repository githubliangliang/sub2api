# Why

现有统计在平台过滤之外硬编码gpt前缀，真实SQLite探针证实遗漏OpenAI非gpt模型，并令Claude/Grok平台选择返回空结果。旧第三档据此明确调整为第一档。

# What Changes

修正现有统计的模型范围，复用既有平台/group过滤，调整既有卡片说明；不新增统计入口，不改变时长加权TPS、时间半开区间、TopN/分页、费用或账务。

# Impact

现有Token统计的模型与平台筛选一致性，仅改现有消费者。保持VERSION1.1.28、Go1.27.4、SQLite230/auth21、依赖与资源默认。

# Non-goals

其它按需功能、支付/购买/续费/充值/退款、发布/push/归档和业务实例操作不在本批范围。
