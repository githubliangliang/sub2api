同步上游版本与内容
==================

1) 上游 v0.2.15：使用日志输出 TPS（#7911，本 fork 实现 0e38d06d8）

   - 管理员和用户使用记录共用延迟区域，展示 output_tokens × 1000 / duration_ms，保留一位小数并标注 tok/s。总耗时包含首字等待；输出 Token 已含推理用量，不重复相加。
   - 100 Token、2000ms 总耗时、1500ms 首字等待显示 50.0 tok/s；极小正数仍显示 0.0 tok/s，与不可用标记区分。缺失、非有限、非正数，图片输出/图片计费及 Live/unknown 等类型显示不可用；图片输入后的文本输出仍可计算。
   - 延续两个页面各自的延迟列显隐偏好，翻页或刷新按当前记录更新。不增加 API、账本或数据库 TPS 字段；不取同 PR 的运维百分位统计或 PG 查询。

2) 上游 v0.2.16：运维账号名与规则作用范围（#7933、#7828，本 fork 实现 0e38d06d8）

   - #7933：成功/错误请求详情在桌面表格和移动卡片显示当前账号名称，已删除或不可见账号回退为 #ID，无合法正数 ID 显示 -。主明细先显示，名称异步补齐，查询失败不影响明细、分页和 TTFT/总耗时排序。
   - 名称查询复用不含凭据的 lite 账号接口，关闭调度评分聚合；分页有页数、空页及重复页终止条件。60 秒缓存合并并发加载，支持手动失效、缺项每轮至多一次额外刷新、登录会话隔离；快速翻页、关闭、重新登录及迟到响应不串页。连续手动刷新替换旧快照，从错误详情返回时保留上下文并续接名称加载。
   - 按用户后续选择，恢复完整 /admin/ops 页面、侧栏与菜单管理项，standard/simple 模式管理员均可使用；仍受监控开关、隐藏菜单和管理员权限约束，其他页面限制与既有运维指标口径保留。
   - #7828：已有临时不可调度规则支持 account/model 显式范围，创建默认 model，编辑旧规则等价回显并保留顺序。缺失/非法 scope 沿用旧语义：模型已知的非 401 走模型级，其余回退原账号级或鉴权处理；第一条匹配规则决定范围。
   - 模型级冷却采用实际映射目标及既有调度键，只隔离对应账号/模型组合；图片和文本模型继续分开。状态诊断包含 scope/model；到期恢复，模型状态写失败仍按预算换号，不扩大为账号全局暂停或运行时熔断。
   - API Key 的非凭据模型权限 401 可使用显式 model 规则；OAuth、SetupToken、影子账号以及明确 token_invalidated/token_revoked/Unauthorized 等凭据失败保留原鉴权、刷新和停号语义，不被模型规则吞掉。保留池模式、Grok 团队键、普通/粘性/WS 选择及真实配额窗口。

3) 上游 v0.2.17：OpenAI API Key 搜索模拟与最小输出 Token（#8080、#8094，本 fork 实现 0e38d06d8）

   - #8080：OpenAI API Key 的 /v1/messages 在 Responses/raw Chat 转换前，可复用既有搜索管理器、提供商及代理执行 Web Search 模拟。必须同时满足全局开启、管理器可用、恰有一个受支持搜索工具和账号/渠道策略；不再调用所选 LLM 上游。
   - 创建/编辑账号支持 default/enabled/disabled 三态，default 继承当前渠道的 openai 标志，enabled/disabled 显式覆盖，旧 true/false 分别兼容 enabled/default。补齐 OpenAI 渠道开关的读取、保存和回显，切换账号、类别或平台不串写，Anthropic 既有模拟保留。
   - JSON/SSE 返回完整 Anthropic 工具引用和唯一终态，采用最后用户消息的既有文本提取规则并保留请求侧模型。OAuth、SetupToken、影子、混合工具、其他入口不进入新增模拟路径。
   - 代理失败按输出前预算换号，输出后写错或取消不重放、不补伪成功，释放并发/串行资源。每个 SSE 事件在 Write/Flush 边界检查取消；搜索沿用零 LLM Token 口径，不按结果文本长度伪造用量。入队前快照请求归属，Gin 复用后仍正确记录本次用户/API Key/分组/账号/模型并保持一次结算。
   - #8094：新增 gateway.min_output_tokens，默认 128、最低 16，支持 YAML 和 GATEWAY_MIN_OUTPUT_TOKENS，按既有配置优先级生效。显式 0、负数、低于 16、非整数和溢出值在弱解码前返回字段级错误。
   - 已有 Chat→Responses、Anthropic→Responses、Anthropic→Chat 转换，对有效显式正数上限取 max(请求值,配置值)，保留双字段优先级和未指定/非正数原行为。配置属于服务实例，旧公共包装器及 nil/未初始化配置继续使用 128，无可变全局下限。
   - 原生 Responses、compact、WS 首帧/后续帧、原样透传、原生 Claude 探针及 OAuth 搜索历史保持原语义，Ollama 等既有 provider cap 仍约束最终请求。此值是转换时请求输出上限的下限，不保证模型实际输出长度；不引入缺失 legacy messages 入口。

4) 上游 v0.2.18：账号筛选记忆（#8142，本 fork 实现 0e38d06d8）

   - 仅持久化平台、状态两个筛选项；重新进入或刷新账号页时，在第一次列表请求前恢复，避免先发无筛选请求。切换筛选仍回第一页并清理选择，保持既有排序、刷新和 ETag 流程。
   - 使用本地现有五平台和实际状态选项校验，非法字段独立回落，保留另一个合法字段；坏 JSON、null/数组和存储读写异常不阻断页面。支持清空保存，不新增搜索词、分组、凭据或勾选项的持久化，不扩展平台目录或改成紧凑筛选布局。
